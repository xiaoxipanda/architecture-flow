# 角色素材

两套 PNG 均为1536×1024 RGBA、三列两行，每格512×512；保留原始透明图集，通过纹理区域绘制，不必重新生成或破坏原图。索引在 ../assets/mascots/manifest.json。附带素材不含视频、账号配置、聊天记录或生产数据。

| 图集 | 从左到右、从上到下 | 识别特征 |
|---|---|---|
| workstreams.png | research / product / dev / content / sales / ops | 黄色眼镜 / 蓝色贝雷帽 / 紫色耳机 / 品红墨镜 / 绿色领结 / 珊瑚色耳麦 |
| expansion.png | founder / reviewer / finance / support / legal / data-analyst | 橙色皇冠 / 薄荷绿放大镜 / 奶油黄计算器 / 浅蓝紫白耳麦 / 深青天平 / 杏桃柱状图 |

Founder与Reviewer可用于当前架构；后四个是备用设计，只有项目实际配置或用户明确要求概念规划时才加进架构。模板默认使用第一套六个工作流角色，扩展图集已附带但不自动启用。

素材由内置 image_gen 生成；第二套使用第一套作为风格参考。提示词见 [第一套](workstreams-prompt.md) 和 [第二套](expansion-prompt.md)。生成来源说明不等于附加第三方商标或素材许可；不擅自作开源许可声明。

新增角色保持细密毛绒材质、小黑眼睛、柔和立体照明、简洁轮廓与小尺寸可读的配饰，用色彩和轮廓区分。明确透明背景、独立留白、不含文字、水印或品牌标记。生成后检查 alpha 与角色是否完整，保存新图集及矩形索引，避免覆盖旧素材。
